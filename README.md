A single editorial front page that sums up Friday 27 November 2026 in one
image: the drone attack in Kuwait that killed two Italian technicians, the
Houthi strike on Aramco's Jazan refinery, Israeli strikes in Gaza, the
Bangkok refinery fire, the first-ever postponement of the 100th Macy's
Thanksgiving Day Parade, and UK net migration falling to its lowest since
1997 — plus chess, North Korea, and sport in brief. All facts verified
against Reuters, BBC, AP and AFP reporting from 27 November 2026.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024 PNG, under 1 MiB). The program uses no
network and no randomness: running it twice produces byte-identical output.
`draw.py` holds the renderer; `main.py` is the entrypoint.
